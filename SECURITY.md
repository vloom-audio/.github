# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Instead, use GitHub's private vulnerability reporting
(**Security → Report a vulnerability** on the affected repository), or email
**contact@vloom-audio.com** with:

- the affected repository and version or commit
- steps to reproduce, or a proof of concept
- the impact you expect

We aim to reply within 7 days and will credit you in the release notes unless
you prefer to stay anonymous.

## Supported versions

Vloom Audio software is in early development. Only the latest release and the
`main` branch receive fixes.
