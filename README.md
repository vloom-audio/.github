# vloom-audio/.github

Organisation-wide files for [Vloom Audio](https://github.com/vloom-audio).

- `profile/README.md` — the page shown at github.com/vloom-audio
- `FUNDING.yml` — the Sponsor button on every repository
- `CONTRIBUTING.md`, `CODE_OF_CONDUCT.md`, `SECURITY.md` — default community files
- `ISSUE_TEMPLATE/`, `PULL_REQUEST_TEMPLATE.md` — default issue and PR forms

Any repository that has its own copy of one of these files uses its own instead.
This repository must stay **public** for GitHub to apply them.
