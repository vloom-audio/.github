# Vloom Audio

Free, 100% open-source music software for macOS, Windows and Linux.

### 🎛️ VloomDAW

A pattern-based digital audio workstation in the spirit of FL Studio:
channel rack, step sequencer, piano roll, playlist and mixer.
Early development — follow along, try the builds, and help shape it.

| Repository | What it is |
|---|---|
| [VloomDAW](https://github.com/vloom-audio/VloomDAW) | The desktop app (C++20, Qt 6) |
| [vloom-engine](https://github.com/vloom-audio/vloom-engine) | The real-time audio engine (C++20, no UI) |
