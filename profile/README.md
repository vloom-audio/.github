## 🎛️ About VloomDAW

**VloomDAW** is a fast, modern, pattern-based Digital Audio Workstation built in the spirit of FL Studio—designed from the ground up for beatmakers, producers, and sound designers who want a native, cross-platform workflow without proprietary lock-in.

> 🚧 **Status: Early Development** — We are actively building the core DSP library, audio engine, and UI. Follow along, test early builds, and help shape the future of open-source music production!

### ✨ Core Workflow Highlights

* **🥁 Channel Rack & Step Sequencer** — Rapidly sketch beats, drum loops, and rhythmic ideas.
* **🎹 Piano Roll** — Expressive MIDI editing designed for speed and musicality.
* **🎞️ Arrangement Playlist** — Flexible pattern, audio, and automation arrangement.
* **🎚️ Real-Time Mixer** — Low-latency routing, metering, and effects processing.
* **⚡ Native Performance** — Powered by modern **C++20** for deterministic, real-time audio performance.

## 📦 Ecosystem & Repositories

Our modular architecture cleanly decouples the desktop interface, the real-time audio engine, and core signal processing primitives to ensure maximum stability, reusability, and testability.

| Repository | Description | Tech Stack | Status |

| [**VloomDAW**](https://github.com/vloom-audio/VloomDAW) | The cross-platform desktop application & user interface | `C++20` `Qt 6` | 🔨 Active Dev |
| [**vloom-engine**](https://github.com/vloom-audio/vloom-engine) | Headless, real-time audio graph, routing & MIDI engine | `C++20` `Real-Time Audio` | 🔨 Active Dev |
| [**vloom-dsp**](https://github.com/vloom-audio/vloom-dsp) | Core digital signal processing primitives, filters, oscillators & effects | `C++20` `DSP` `Audio Math` | 🔨 Active Dev |
